# Personal Website Project
## Overview
README          | Description and user guide.
.gitignore      | Instructions to ignore files and folders that are specific to the local environment used for local
                  development.
vite_website    | Actual project for the website, build with Vite.

## Instructions
1. Install Node & npm, Yarn, pnpm, etc. on your local machine. The instructions will be written for pnpm.
2. Installing the project dependencies: pnpm install
3. To start the local development server: pnpm vite
4. To stop the local development server: q + enter
